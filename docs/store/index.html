Guía Técnica de Producción y Marketing para Aplicaciones Móviles

Esta guía detalla de forma puramente técnica y procedimental cómo resolver los cuatro elementos críticos exigidos por la rúbrica para alcanzar la calificación máxima de 10 puntos (RA5.ce2 y RA5.ce5).

1. Iconos de la Aplicación (Adaptive Icons para Android)

Google Play exige iconos adaptativos. Esto significa que el icono se compone de dos capas independientes (primer plano y fondo) para que el sistema operativo pueda aplicar efectos de paralaje, máscaras de recorte y animaciones dinámicas según el fabricante.

Requisitos de Archivos Fuente:

  • icon-foreground.png (Capa de primer plano): Tamaño obligatorio de 1024x1024 px con fondo transparente. El logotipo o elemento visual clave debe estar estrictamente dentro del "área segura" central (círculo central de 660 px de diámetro) para evitar recortes forzados.
  • icon-background.png (Capa de fondo): Tamaño de 1024x1024 px. Un color sólido o un patrón texturizado sin logotipos ni letras.

Procedimiento Automático de Generación (Capacitor Asset Tool):

  1. Crea una carpeta llamada assets en la raíz de tu proyecto Capacitor/Ionic.
  2. Guarda dentro de ella tus archivos icon-foreground.png e icon-background.png.
  3. Instala global o localmente la utilidad oficial ejecutando en tu terminal: 
    npm install @capacitor/assets --save-dev
  4. Ejecuta el comando de generación para inyectar los recursos automáticamente en el proyecto nativo de Android: 
    npx capacitor-assets generate --android

Resultado en el proyecto: Este comando crea de forma limpia todas las densidades requeridas (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi) dentro del directorio nativo android/app/src/main/res/ eliminando permanentemente los assets por defecto de Ionic.

2. Pantalla de Bienvenida (Splash Screen Eficiente)

La pantalla de inicio/bienvenida evita que el usuario visualice un lienzo en blanco mientras el motor web de Capacitor carga el bundle de JavaScript en memoria.

Requisitos del Archivo Fuente:

  • splash.png: Una imagen de 2732x2732 px. Debe tener un diseño centrado con un margen de seguridad masivo a los lados, ya que la imagen se recortará dinámicamente según la relación de aspecto del dispositivo (pantallas panorámicas, tablets o móviles plegables).

Procedimiento de Generación e Integración:

  1. Coloca el archivo splash.png dentro de la carpeta assets/ creada anteriormente.
  2. Ejecuta el generador de assets para procesar y compilar la splash screen: 
    npx capacitor-assets generate --android
  3. Para asegurar que la transición entre la pantalla nativa y la web app sea fluida sin parpadeos blancos, instala el plugin oficial de Capacitor Splash Screen: 
    npm install @capacitor/splash-screen
npx cap sync android
  4. Configura el comportamiento en el archivo de configuración de tu proyecto (capacitor.config.json): 
    {
  "plugins": {
    "SplashScreen": {
      "launchShowDuration": 2000,
      "launchAutoHide": true,
      "backgroundColor": "#1e3a8a",
      "androidSplashResourceName": "splash",
      "showSpinner": false
    }
  }
}

3. Vídeo de Demostración Promocional

Para cumplir el criterio de marketing sin un presupuesto comercial, debes enfocar el vídeo como un screencast técnico/comercial de alta fidelidad con una duración ideal de 30 a 45 segundos.

Guion Técnico de Grabación (Estructura de Tres Actos):

Segmento Duración Acción Visual en la App Objetivo Técnico (Rúbrica)
01. Gancho / Inicio 0:00 - 0:07 Apertura de la app desde el escritorio móvil. Se aprecia el icono personalizado y la Splash Screen cargando instantáneamente. Demostrar la correcta integración estética nativa del sistema.
02. Flujo Principal 0:07 - 0:25 Uso de la funcionalidad core: El usuario abre la cámara, toma una foto geolocalizada e inmediatamente se renderiza un pin en el mapa interactivo. Validar el funcionamiento libre de fallos de los plugins de Hardware (Cámara, GPS).
03. Llamada a la Acción 0:25 - 0:35 Cierre mostrando un plano limpio de la interfaz y un rótulo con la URL de descarga (GitHub Pages). Cerrar el ciclo de la estrategia de marketing y distribución.

Herramientas y Producción Recomendadas:

  • Captura: Utiliza el grabador de pantalla nativo de Android o el comando adb shell screenrecord /sdcard/demo.mp4 desde tu terminal conectado por depuración USB para obtener la máxima tasa de frames sin compresión destructiva.
  • Postproducción: Importa el archivo en CapCut, Canva o Clipchamp. Añade un lienzo de fondo con un mockup (marco de smartphone), recorta los tiempos muertos de carga (como el retraso de enfoque de la cámara) y añade textos cortos en tipografía moderna que rotulen la acción ("Captura", "Geolocaliza", "Navega"). Exporta estrictamente a 1080p, 60fps, formato H.264/MP4.

4. Página Web de Publicidad (Landing Page de Conversión)

La Landing Page debe ser una sola página estática y ligera orientada puramente a la descarga directa del instalador. Para obtener la máxima puntuación en marketing (RA5.ce5), debe alojarse directamente en GitHub Pages dentro del mismo repositorio de tu proyecto en la carpeta /docs.

Estrategia de Despliegue en un Click:

  1. Crea una carpeta llamada docs en la raíz de tu proyecto donde tienes el archivo package.json.
  2. Guarda el código anterior como docs/index.html.
  3. Pon tu archivo ejecutable compilado app-release.aab dentro de la misma carpeta docs/. De este modo, el botón de descarga del instalador funcionará de manera local e inmediata sin enlaces caídos.
  4. Haz un commit y push de tus cambios a tu repositorio de GitHub.
  5. Entra en la configuración de tu repositorio en GitHub (Settings > Pages), bajo la opción "Build and deployment", selecciona la rama principal (main o master) y cambia explícitamente la carpeta de despliegue de / (root) a /docs. Haz clic en guardar.

¡Listo! En menos de 2 minutos tu web de publicidad estará online en una URL pública parecida a https://tu-usuario.github.io/tu-repositorio/, cumpliendo a la perfección el criterio de máxima nota para marketing de la ficha técnica.
